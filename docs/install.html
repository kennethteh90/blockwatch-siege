Setup · ~5 minutes

Install & deploy.

Blockwatch: Siege is a vanilla datapack — no client mods, no Forge, no Fabric. Pick the install method that matches where you play, copy one folder, run /reload, and you're in.

What you need

EditionMinecraft Java Edition
Version1.20.4 (pack_format 26)
Players1–4 cooperative
WorldFlat world recommended (default coords assume Y=64)
Newer Minecraft? Update pack.mcmeta's pack_format to match. See the Minecraft Wiki's pack-format table.

Pick your install method

1

Find your world folder.

Open the directory for your operating system:

Windows%APPDATA%\.minecraft\saves\<WorldName>\
macOS~/Library/Application Support/minecraft/saves/<WorldName>/
Linux~/.minecraft/saves/<WorldName>/
2

Copy the datapack folder.

Drop blockwatch_siege/ into the world's datapacks/ folder. The structure should look like this:

<WorldName>/
  datapacks/
    blockwatch_siege/
      pack.mcmeta
      data/
        ...
3

Reload the world.

Open the world (or run /reload if it's already open). You should see this message in chat:

[Blockwatch: Siege] Reloaded. v0.1.0
4

Start your first match.

/function blockwatch:state/new_match

Eight build pads will appear. Head to How to play to learn the controls.

1

Copy to the server's world folder.

<server-root>/
  world/
    datapacks/
      blockwatch_siege/   ← copy here
2

Reload from console or chat.

From the server console:

reload confirm

Or from any operator account in-game: /reload. A full server restart also works.

3

Start the match.

/function blockwatch:state/new_match

The datapack is co-op compatible by default — gold is shared across @a, castle HP is global. Increase #castle.max bw.cfg for larger groups.

1

Zip the datapack folder.

Navigate into datapack/, then zip blockwatch_siege/. The archive's root must contain pack.mcmeta directly — no extra nested folder.

blockwatch_siege.zip
  blockwatch_siege/
    pack.mcmeta
    data/
      ...
2

Drop the zip into datapacks/.

Recipients drop the .zip directly into their world's datapacks/ folder. Minecraft reads zipped datapacks natively — no extraction needed.

3

Reload.

Same as the other methods: /reload in-game, look for the v0.1.0 message in chat.

First-match checklist

After installing, run through this list to confirm everything's wired up.

// CHECK_LIST

  • Chat shows [Blockwatch: Siege] Reloaded. v0.1.0
  • Run /function blockwatch:state/new_match — 8 pads appear
  • Build timer counts down in the sidebar
  • Place a tower: /trigger bw.place set 1 on a pad
  • Wait for combat (or jump ahead with /function blockwatch:state/set_combat)
  • Enemies spawn and walk toward the castle
  • Towers fire automatically
  • Wave clears, intermission triggers, gold is awarded

Recommended gamerules

These are applied automatically by map/setup.mcfunction, but running them up front keeps things clean from world load.

/gamerule doDaylightCycle false
/gamerule doWeatherCycle false
/gamerule doMobSpawning false
/gamerule doFireTick false
/gamerule naturalRegeneration false
/gamerule keepInventory true

Troubleshooting

// No reload message in chat Confirm pack.mcmeta is at the root of blockwatch_siege/, not nested inside another folder. Then run /datapack list to verify the pack loaded.
// Pads spawn at strange coordinates The defaults assume a flat world at Y=64. For custom maps, run /function blockwatch:map/config to print every hardcoded coordinate, then edit map/pads.mcfunction and the lane move files.
// Towers won't place You must be standing on a pad and not have a tower already there. Pads with towers show a different label. The trigger is one-shot — re-enable with /scoreboard players enable @s bw.place if it gets stuck.

Uninstall

Delete the datapack folder, run /reload, then optionally clean up scoreboards and lingering entities:

/scoreboard objectives remove bw.state
/scoreboard objectives remove bw.wave
/scoreboard objectives remove bw.castle_hp
/scoreboard objectives remove bw.gold
/scoreboard objectives remove bw.cfg
/kill @e[tag=bw.enemy]
/kill @e[tag=bw.tower]
/kill @e[tag=bw.pad]
