Player guide

How to play.

A round of Blockwatch: Siege takes about twenty minutes. Build, defend, intermission, repeat — ten times, then a boss. Here's the loop, the commands you'll actually use, and the full wave breakdown.

Commands cheatsheet

The four you'll actually use.

Every other command is admin/debug. These are what you type during play.

// START A MATCH

/function blockwatch:state/new_match

Sets up pads, resets gold to 100g, drops you into BUILD. Run once at the start of a session.

// PLACE A TOWER

/trigger bw.place set 1

Stand on a pad. 1 Arrow · 2 Frost · 3 Bomb. The pad must be empty.

// SELL NEAREST

/trigger bw.sell set 1

Refunds ~70%. Must be within 4 blocks of the tower. Only works during BUILD or INTERMISSION.

// CHECK STATE (DEBUG)

/scoreboard players get #state bw.state

Returns the current FSM state (1–6). Useful when something feels stuck.

Strategy notes

Tips from the front line.

// OPEN WITH ARROWS

Two Arrow towers on lane 1 will carry you through wave 4. Don't overspend early — you need 100g saved by wave 3 to drop your first Bomb.

// FROST IS A FORCE MULTIPLIER

A Frost tower alone deletes nothing. Pair it with Arrow or Bomb behind so frozen enemies eat real damage while they're locked in place.

// CENTER YOUR BOMBS

From wave 7 onward both lanes are active. A Bomb tower placed between the lanes at 10-block range can hit enemies in both lanes simultaneously.

// SAVE FOR THE BOSS

Wave 10's ravager has 200 HP. Plan your wave-9 intermission with at least one Frost in lane 1 and two Bombs nearby. Otherwise it walks through.

// SELL UNDERPERFORMERS

~70% refund means selling and rebuilding is rarely a big loss. If a tower is firing into thin air, move it.

// CHASE FLAWLESS

+50g for every wave with zero leaks. Two flawless waves pays for a Bomb tower. It's worth playing carefully.
